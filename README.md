# The Tote Bag Paradox

Dashboard interaktif survei tote bag, Kelompok 7, Kelas K33.

**Dashboard:** https://athaillahbagas.github.io/totebag-dashboard/

## Isi

- Empat indikator utama dan delapan grafik.
- Filter jumlah tas, pilihan kemasan, dan pengalaman menerima tas restoran.
- Tabel respons anonim dan sumber perhitungan untuk setiap grafik.

## Data dan batas interpretasi

Snapshot 17 November 2026, periode respons 28 Oktober–16 November 2026. Terdapat 37 isian dengan 36 responden unik. Satu respons ganda sementara menggunakan isian terbaru; 37 isian anonim tetap tersedia untuk audit. Basis analisis tas restoran adalah 31 responden yang pernah menerimanya.

Data hanya menggambarkan responden kelas dan tidak mengukur ecological footprint atau hubungan sebab-akibat. Nama, NIM, dan tautan lembar respons mentah tidak disertakan. Data tidak diperbarui otomatis dari Google Sheets.

## Menjalankan

Buka `index.html` di browser atau gunakan tautan GitHub Pages. Aplikasi dan data terbundel dalam satu file HTML dan tidak memerlukan proses build pada GitHub Pages.
